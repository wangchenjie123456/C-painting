# 画图软件设计说明文档

直接点击luxintao.exe - 快捷方式访问可执行文件

## 一、设计思想

本软件旨在开发一个基于 Windows 平台的图形绘制与图像处理工具，具备基本绘图能力、图像特效应用、颜色填充与界面交互体验，适用于教学实践与日常图像编辑需求。设计中采用了 C# 的 WinForms 技术，充分利用 GDI+ 图形库实现图形渲染与图像操作。

## 二、设计方法

### 1. 开发环境与技术

- **开发语言**：C#

- **开发平台**：.NET Framework + WinForms

- **图形绘制**：使用 `Graphics`、`Pen`、`Brush`、`Bitmap` 等 GDI+ 类

- **图像处理**：通过 `ToolUtils` 类实现多个像素级图像滤镜

### 2. 模块划分与职责

| 模块               | 功能说明                          |
| ---------------- | ----------------------------- |
| MainForm（主窗体）    | 主界面、绘图逻辑、菜单处理、功能入口            |
| ToolUtils（工具类）   | 封装图像特效：浮雕、黑白、雾化、马赛克、锐化、柔化、灰度等 |
| SetGradient_Form | 设置渐变色填充方式与预览                  |
| SetHatch_Form    | 设置纹理填充样式，使用 `HatchBrush` 绘制   |
| SetSize_Form     | 设置画布尺寸（宽度与高度）并同步修改            |
| 用户交互             | 鼠标拖拽绘图、多边形点选、双击结束、多种填充模式切换    |

## 三、工具类说明：ToolUtils

由于项目开发时，对bitmap的像素级处理不熟悉，参考了国外团队的toolutils开源图像处理工具类，设计了自己的ToolUtils像素级处理工具类。

`ToolUtils` 是本项目中的图像处理工具类，封装了多种像素级滤镜算法。该类中函数全部采用**中文拼音命名风格**，语义明确，便于理解和维护。例如：

```csharp
ToolUtils.fudiao(...)              // 浮雕效果
ToolUtils.heibaixiaoguo(...)       // 黑白图像
ToolUtils.rouhuaxiaoguo(...)       // 柔化（高斯滤波）
ToolUtils.ruihua(...)              // 锐化（拉普拉斯模板）
ToolUtils.huidu(...)               // 灰度处理（色彩矩阵变换）
ToolUtils.wuhuaxiaoguo(...)        // 雾化（像素随机扰动）
ToolUtils.masaike(...)             // 马赛克效果
ToolUtils.DrawPolygon(...)         // 绘制多边形（路径填充与描边）
```

命名统一、注释规范，代码结构良好。

## 四、实现过程中的问题与解决方案

| 问题          | 解决策略                                      |
| ----------- | ----------------------------------------- |
| 鼠标绘图闪烁、图像残影 | 使用临时图像副本，每次绘制前先恢复原图                       |
| 多边形绘制无法准确控制 | 使用点列表（`ArrayList`），双击结束绘制                 |
| 特效处理时界面卡顿   | 使用异常处理机制 + 处理后刷新界面预览                      |
| 图像尺寸修改无效    | 主窗体绑定 `ImageWidth` 和 `ImageHeight` 属性统一更新 |
| 填充颜色不一致     | 将颜色与填充类型集中管理（通过 `ColorType` 变量）           |

## 五、软件功能说明

### 1. 文件操作

- 新建：清空画布，准备绘制

- 打开：加载本地图片（支持 JPG、PNG、BMP 等格式）

- 保存/另存为：保存当前画布为图片文件

- 退出：关闭程序（含保存提示）

### 2. 图形绘制

支持多种图形元素：

- **线段**：直线、折线、自由线

- **几何图形**：矩形、椭圆、圆形

- **多边形**：点击点位绘制，双击完成

- **文字输入**：支持文本框形式输入文字

所有绘图均支持：

- 线型（实线、虚线、点划线）

- 线宽设置

- 起点/终点样式（如箭头）

### 3. 填充方式

- **纯色填充**：选择一种颜色用于图形填充

- **渐变填充**：设置起始色与终止色，支持多方向

- **纹理填充**：使用 `HatchStyle` 创建图案纹理

- **图像填充**：使用外部图像作为填充材质

设置界面均提供实时预览。

### 4. 图像处理与特效

使用 `ToolUtils` 类实现如下滤镜功能：

- 灰度处理

- 黑白处理（加权平均法）

- 锐化（拉普拉斯）

- 柔化（高斯）

- 浮雕

- 雾化

- 马赛克

- 反色（可选）

特效处理后自动刷新图像。

### 5. 图像变换

- **旋转**：顺时针、逆时针旋转图像

- **翻转**：水平、垂直翻转

- **缩放**：设置图像显示尺寸或恢复实际大小

## 六、操作说明

1. **选择绘图工具**：在菜单栏中选择线段、图形、文字等

2. **设置颜色和样式**：选择线宽、线型、填充方式

3. **在画布上绘制**：鼠标点击拖动或点选

4. **使用菜单处理图像**：应用滤镜、修改尺寸、保存文件等

5. **退出软件**：文件 → 退出
